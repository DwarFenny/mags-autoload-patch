Mags Autoload Patch for S.T.A.L.K.E.R. GAMMA

ENGLISH
Automatically tops up incomplete Loadout magazines. Optional ammo balancing
evens out rounds between Loadout magazines, uses loose ammo first, and unloads
only what is needed. You can also unload magazines outside the Loadout.

Default keys: B - autoload (or balancing when enabled with the shared key);
C - unload outside-Loadout magazines (off by default).
Settings and key bindings: Options -> MCM -> Mags Autoload.

Installation:
1. Download the latest ZIP from Releases.
2. In MO2, choose "Install a mod from archive" and select the ZIP.
3. Enable the mod.

GAMMA Mags Reloaded 1.05 is required. Animated Magazine Loading (AML) is
optional. To use it, enable AML Compatibility and set Load behavior to
"Individual" in Mags Reloaded MCM. In MO2, place "[Working for Animated
Magazine Load]" below "GAMMA.Mags.Reloaded-1.05".

POLSKI
Automatycznie doladowuje niepelne magazynki Loadoutu. Opcjonalne balansowanie
wyrownuje amunicje miedzy magazynkami, najpierw uzywa luznych nabojow i
rozladowuje tylko tyle, ile potrzeba. Mozesz tez rozladowac magazynki spoza
Loadoutu.

Domyslne klawisze: B - autoload (lub balansowanie, gdy jest wlaczone i uzywa
wspolnego klawisza); C - rozladowanie magazynkow spoza Loadoutu (domyslnie
wylaczone).
Ustawienia i klawisze: Options -> MCM -> Mags Autoload.

Instalacja:
1. Pobierz najnowszy ZIP z zakladki Releases.
2. W MO2 wybierz "Install a mod from archive" i wskaz ZIP.
3. Wlacz mod.

Wymagany jest GAMMA Mags Reloaded 1.05. Animated Magazine Loading (AML) jest
opcjonalny. Aby go uzyc, wlacz AML Compatibility i ustaw Load behavior na
"Individual" w MCM Mags Reloaded. W MO2 ustaw "[Working for Animated Magazine
Load]" ponizej "GAMMA.Mags.Reloaded-1.05".
