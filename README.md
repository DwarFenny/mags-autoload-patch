# Mags Autoload Patch

## English

A small add-on for S.T.A.L.K.E.R. GAMMA and GAMMA Mags Reloaded. It handles
your Loadout magazines so you can spend less time clicking through inventory.

- **Autoload:** tops up incomplete Loadout magazines using their loaded ammo
  type or magazine mark.
- **Balance:** optionally evens out ammo across compatible Loadout magazines.
  It uses loose ammo first and unloads only the surplus needed. Off by default.
- **Unload:** unloads magazines outside the Loadout. Off by default.
- **AML support:** can continue a queue after closing inventory. Drawing a
  weapon or using an item cancels it; sprint behavior is configurable.

Default keys: **B** for autoload (or balancing when enabled with the shared
key); **C** for unloading outside-Loadout magazines.

### Installation

1. Download the latest ZIP from [Releases](https://github.com/DwarFenny/mags-autoload-patch/releases).
2. In MO2, select **Install a mod from archive** and choose the ZIP.
3. Enable the mod.

GAMMA Mags Reloaded 1.05 is required. Animated Magazine Loading (AML) is
optional. To use AML, enable **AML Compatibility** and set **Load behavior**
to **Individual** in Mags Reloaded MCM. In MO2, place
**[Working for Animated Magazine Load]** below
**GAMMA.Mags.Reloaded-1.05**.

### Settings

Open **Options → MCM → Mags Autoload** to change keys, enable balancing or
unloading, adjust speed, and choose sprint behavior.

## Polski

Niewielki dodatek do S.T.A.L.K.E.R. GAMMA i GAMMA Mags Reloaded. Zajmuje się
magazynkami Loadoutu, żebyś nie musiał przeklikiwać ekwipunku.

- **Autoload:** doładowuje niepełne magazynki Loadoutu amunicją pasującą do
  ich zawartości lub oznaczenia.
- **Balansowanie:** opcjonalnie wyrównuje amunicję w zgodnych magazynkach
  Loadoutu. Najpierw zużywa luźne naboje, a z magazynków wyciąga tylko
  potrzebną nadwyżkę. Domyślnie wyłączone.
- **Rozładowywanie:** rozładowuje magazynki spoza Loadoutu. Domyślnie wyłączone.
- **Obsługa AML:** kolejka może działać po zamknięciu ekwipunku. Wyciągnięcie
  broni lub użycie przedmiotu ją przerywa; zachowanie podczas sprintu ustawisz
  w MCM.

Domyślne klawisze: **B** — autoload (lub balansowanie, jeśli jest włączone
i używa wspólnego klawisza); **C** — rozładowanie magazynków spoza Loadoutu.

### Instalacja

1. Pobierz najnowszy ZIP z zakładki [Releases](https://github.com/DwarFenny/mags-autoload-patch/releases).
2. W MO2 wybierz **Install a mod from archive** i wskaż ZIP.
3. Włącz mod.

Wymagany jest GAMMA Mags Reloaded 1.05. Animated Magazine Loading (AML) jest
opcjonalny. Aby z niego korzystać, włącz **AML Compatibility** i ustaw
**Load behavior** na **Individual** w MCM Mags Reloaded. W MO2 ustaw
**[Working for Animated Magazine Load]** poniżej
**GAMMA.Mags.Reloaded-1.05**.

### Ustawienia

Wejdź w **Options → MCM → Mags Autoload**, aby zmienić klawisze, włączyć
balansowanie lub rozładowywanie, dostosować prędkość i wybrać zachowanie
podczas sprintu.
